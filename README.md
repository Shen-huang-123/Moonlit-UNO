# 月下UNO Android 项目

原生 Android 四人 UNO 游戏，采用墨青夜色、月下山景、半透明深蓝面板和细金边。支持离线 AI 与局域网联机，无需账号。

- 当前版本：0.5.0。
- [安装最新版 APK](安装包/最新版/月下UNO-v0.5.0.apk)。支持 Android 6.0 及以上，当前为调试签名体验版。
- Android Studio 打开 `源码/月下UNO/`。
- [版本记录](发布/版本记录.md) · [联机验收记录](源码/月下UNO/验证/v0.2-局域网验收.md)。

## 体验与联机

单人点击「开始对局」，与三位 AI 同桌。手牌左右滑动，点亮的牌可以打出；万能牌弹出选色菜单。剩两张时先按 UNO 再出牌，漏喊罚摸两张。

联机时所有手机安装相同的 v0.5，并连接同一 Wi-Fi 或房主热点。房主选择「局域网联机 → 创建房间」，其余玩家输入房间显示的 IPv4 地址加入。至少两人可开局，共四席，空席由 AI 补位；结束后房主可再开一局。

房主统一校验规则和同步牌局，每台手机只接收自己的牌面。客人断线由 AI 接管，房主退出关闭房间。当前不支持自动搜房、中途加入、断线重连和房主迁移。连接失败时检查地址及访客网络 / AP 隔离；使用固定 TCP 38571，无需公网服务器。

摸牌后自动过牌，不叠加罚牌、不提供 +4 质疑；+4 仅在没有当前颜色手牌时可用。无音效或对局持久化，系统结束进程后不恢复牌局。

## 构建与验证

需要 JDK 17–24、Android SDK 35；已验证使用 JDK 21。设置 ANDROID_HOME，在 `源码/月下UNO/` 下运行 `./gradlew.bat assembleDebug`。生成 APK 位于该工程的 `app/build/outputs/apk/debug/`。

测试也在工程目录内执行：

```powershell
javac -encoding UTF-8 -d 验证/classes app/src/main/java/com/moon/uno/UnoGame.java app/src/main/java/com/moon/uno/LanRoom.java 验证/RulesCheck.java 验证/LanCheck.java
java -cp 验证/classes RulesCheck
java -cp 验证/classes LanCheck
```

规则检查 47 项通过，包含 30 局完整自动对战；四个真实 TCP 客户端已完成整局，验证手牌保密、越权 / 过期指令拒绝、满房、重开和断线接管。Android 15 模拟器与 JVM 客户端已验证建房、加入和双向摸牌，尚未进行多台物理手机 / 路由器测试。

构建缓存、测试编译产物、模拟器数据和临时日志已清理，并加入忽略规则。

### v0.3.1 · 荣耀 WIN 顶部安全区

修复 Android 15 边到边显示造成的状态栏、挖孔和圆角区域遮挡。界面同时读取系统栏与 DisplayCutout 安全区，顶部栏随系统字号增长；旋转、显示大小、分辨率或字号变化时立即重新布局。大挖孔竖屏及瀑布边横屏专项验收通过，详见 [荣耀 WIN 安全区验收](源码/月下UNO/验证/v0.3.1-荣耀WIN安全区验收.md)。

### v0.4.0 · 丝滑交互

卡牌拥有随触点倾斜、抬起和飞向牌桌的完整动作；无效出牌使用摇动与触感反馈，普通按钮采用快速按压和柔和回弹。新增出牌动作锁，避免快速连点产生重复操作，并保留系统“减少动态效果”设置。

### v0.5.0 · 月夜牌桌视觉升级

对局页改为更有空间感的月夜牌桌：头像席位、当前回合高亮、双层桌面纹样、中心柔光和统一玻璃渐变控件。卡面增加环境投影与斜向高光，背景粒子提升至约 30 帧并保持低强度绘制。
