## 覆盖

每组检查大厅、离线牌局、真实触摸摸牌后的状态、房主房间、客人入席后的房间与联机开局。所有主要视图位于扣除系统栏后的内容区域；手牌仅允许水平方向超出并横向滚动。

- 底部摸牌和 UNO 始终可见，不再依赖整页纵向滚动。
- 竖屏分配剩余高度给牌桌，横屏采用左侧牌桌 / 右侧手牌及操作区。
- 大厅与房间独立适配，短屏先缩装饰，不挤掉主要入口与开局按钮。
- 实际触摸摸牌成功，客人连接并由房主开始联机对局成功。
- 手动测试运行中从 360×640 切换到 800×360，手牌仍为 8 张，底部按钮仍在安全区域内。
- 已查看竖屏、横屏、房间截图。启用 / 禁用系统动画均可用；未发现 AndroidRuntime 崩溃。

## 动效与视觉

月夜光点、月亮和扇形卡牌、细金边牌桌；入场淡入上移、按钮按压回弹、行动方提示、落牌倾斜归位、摸入手牌的短过渡。背景失焦 / 隐藏后停止持续刷新；系统关闭动画时使用静态表现。统一深蓝金边弹窗及四色选色按钮。

## 限制

尚未在物理手机、刘海 / 折叠屏真机、不同路由器上验收。小屏动态文本使用省略，点按牌局状态可查看完整内容；长昵称使用单行省略。

## 复验

在工程目录构建 `gradlew.bat assembleDebug assembleDebugAndroidTest`。安装两个 APK 后运行：

```powershell
adb shell settings put global animator_duration_scale 0
adb shell am instrument -w com.moon.uno.test/com.moon.uno.UiProbe
```

使用 `adb shell wm size`、`adb shell wm density` 与 `adb shell settings put system font_scale` 配置案例。尺寸测试使用实际测量与真实触摸，不依赖截图估算按钮边界。
